## Overview

A complete **Design System** built as a **monorepo** with Turborepo, published to NPM. Features a component library with Storybook documentation, shared TypeScript configs, and ESLint configurations.

## Packages

| Package | Description |
|---|---|
| **@ignite-ui/react** | React component library |
| **@ignite-ui/tokens** | Design tokens (colors, spacing, typography) |
| **@ignite-ui/eslint-config** | Shared ESLint configuration |
| **@ignite-ui/ts-config** | Shared TypeScript configuration |

## Tech Stack

| Technology | Purpose |
|---|---|
| **React** | Component framework |
| **Storybook** | Component documentation |
| **Turborepo** | Monorepo management |
| **TypeScript** | Type safety |
| **Stitches** | CSS-in-JS styling |

## Getting Started

```bash
git clone https://github.com/rafaumeu/ignite-call-design-system.git
cd ignite-call-design-system
npm install
npm run storybook
```
